# Draft tasks

Task files here have `Status: Draft` — an idea that isn't scoped enough to
hand off yet (missing acceptance criteria, out-of-scope boundaries, or a
clear problem statement). Move a file out of this folder to
`docs/tasks/<slug>.md` (top level) the moment you set its `Status: Ready`.

Keep this file even when the folder is otherwise empty, so the folder stays
in git.
