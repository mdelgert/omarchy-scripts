# In-review tasks

Task files here have an open PR: implementation is done and pushed, but the
verify-and-merge step (rerun tests in a throwaway worktree, manually
exercise the change, then merge) hasn't happened yet. Move a file here when
its PR opens; move it to `docs/tasks/done/` (with `Status: Done` and the
Report filled in) once merged.

Keep this file even when the folder is otherwise empty, so the folder stays
in git.
