# Tasks

Each `docs/tasks/<slug>.md` file is one small, assignable unit of work: copy `TEMPLATE.md`, give it a kebab-case slug that matches its `task/<slug>` branch, and mark it Draft until its problem, scope, out-of-scope boundaries, and done criteria make it safe to hand off. Mark it Ready when it is implementable; after merge, complete its report and optionally move it to `done/`. See `docs/AGENT_WORKFLOW.md` for the lightweight branch and review loop.
